# Contributing

Thanks for helping make FreeAgent IDE better.

## Setup

1. Fork and clone the repo
2. Run `install.ps1` / `install.sh` or follow the Development section in the README
3. Use a feature branch: `git checkout -b feat/my-change`

## Guidelines

- Keep the core **local-first** and **telemetry-free**
- Prefer small, focused PRs
- Match existing code style (Python 3.11+, TypeScript React)
- Do not commit secrets, `.env`, or `node_modules`

## PR checklist

- [ ] Change explained in the PR description
- [ ] Install / run still works on your OS
- [ ] Docs updated if behavior changed

## Code of conduct

Be respectful. This project targets students and developers in emerging markets — accessibility and clear errors matter.
